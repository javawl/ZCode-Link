# 什么算已上线：证据与查重

本指南随 [backlink-publish](../SKILL.md) 使用，改编自 link-harness 2.0.0 同名参考文档。

`live` 的标准是：亲自读取**公开、非预览、无需登录**的 URL，核验目标链接作为真正可点击链接存在，其名称与本次锚文本相符，实际目标地址与 `targetUrl` 对应。不得把“浏览器已有登录，所以我能打开”推断成公开可访问。

## 如何核验

1. 用明确的验证页导航到公开列表或详情 URL，再读取 `snapshot`（优先 `format:"aria"`）。等待真实内容加载；不要把 JS 空壳当作已核验。
2. 找到真实 link 角色与对应锚文本。仅有文字中出现域名或 targetUrl 不够；用实际 DOM 的 href、可观测的目标地址或公开页面内容确认链接指向。如果 ARIA 快照没有给出 href，可在已核验页面结构后用 CSS 精确定位 `a[href="真实目标URL"]` 的快照核验名称，或通过独立验证页跟随该链接检查实际去向；重定向要说明。
3. 链接名称与目标必须属于同一个条目/评论，不能拿页脚其他人的相同文字代替。有 canonical URL 或公开详情页时优先记录稳定地址，不记录含令牌的预览链接。
4. 证据写一句到数句中文：核验位置、所见锚文本和目标、回执/审核状态、必要的资料来源。不要记录密码、Cookie、token、验证码或完整邮件正文。

专用浏览器持久保存登录态；**本插件没有独立无痕 context 开关**。若无法据公开页面内容或其他可用的只读公开请求确认匿名可达，应保留 `submitted` 或说明证据不足，不能为了验证导出 Cookie、清空当前 profile 或虚构“已退出登录测试”。

## 不算 live 的情形

| 所见现象                                                | 正确处理                                                 |
| ------------------------------------------------------- | -------------------------------------------------------- |
| 按钮变灰、表单清空、导航成功                            | 检查真实回执，不能据此写 live                            |
| “谢谢提交 / 等待审核”                                   | `submitted`                                              |
| 邮件说已收录，公开页未出现                              | `submitted`，记录邮件提示与公开核验差异                  |
| HTTP 200，但页面只有空壳                                | 等待内容；只有明确提交回执时才保留 submitted             |
| 需要登录、只有作者能看的草稿或带 preview/token 的预览页 | 不能作为 publicUrl 的上线证据                            |
| 显示裸 URL 或被转义的 `<a href=…>` 文本                 | 不算实际链接；已提交的转义内容记 manual_required，不重发 |
| 工具报 `sideEffect:"uncertain"` 或回执丢失              | `failed + manual_required`，先核对，不自动再点提交       |

## 查重口径

页面查重和 live 使用同样的实际链接标准。裸文本或被转义 HTML 不应误判为已发布链接；但**后台已提交记录或历史提交未知仍然阻止自动再发布**。查重失败不能抵消提交幂等规则。

发现既有 `submitted` / `live` 或 publishedUrl 时，本次不认领。只读复核发现已上线，可以在汇总中附新公开证据；状态修复必须走后端实际允许的流程，不能编造租约强行写 live。

## 证据示例

“公开目录详情页可匿名读取，条目中链接名为 ‘Example Tool’，href 指向本次 targetUrl；使用后台资料包。”

“提交后显示 ‘Pending review’，公开列表还没有该条目；有提交回执，记 submitted。”

“最终提交点击后连接中断，无法确认是否进入审核队列；未重试，保留页面供人工核对。”
