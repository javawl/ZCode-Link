# 内容站 / Web2.0 投稿（category: 内容站）

改编自 link-harness 2.0.0 同名 playbook；遵循 [主技能](../../SKILL.md) 的发布范围、查重、租约、页面引用和证据标准。

## 流程

1. 先检查投稿政策、站点主流语言、栏目资格以及目标网站是否已有发布记录。有可用邮箱注册时通过 cloud-mail 注册和验证；Google 登录按 [会话指南](../google-session.md) 处理。
2. 从网站资料包提取实际功能和适用问题，写与网站主题强相关的文章。通常可写 400–800 字，结构为标题、2–3 段正文及必要结语；以目标站实际字数/语言要求和用户内容范围为准。
3. 内容提供可核实的解释、操作或比较，不编造体验、测评数据、客户评价或身份。一篇一般只放一个目标链接，锚文本自然融入正文。
4. 先识别正文编辑器。富文本通过工具栏插入链接；Markdown、HTML、BBCode 只有明确支持时按站点实际格式输入。上传素材优先用资料包，先保存为当前工作区的真实文件。
5. 提交前核对标题、栏目、正文、署名、锚文本与 targetUrl。最终发布一次，不连续点击发布或自动重试未知结果。
6. 打开公开文章 URL 核验真实目标链接；公开可达且核验通过写 live。显示审核中写 submitted，作者预览或草稿不算上线；无法确认提交结果写 manual_required。

## 边界

- 需要申请专栏、个人实名认证、受约束的原创/版权声明或用户提供资质：先确认已有材料与授权，缺失时 manual_required，不代用户作没有依据的保证。
- 平台明确禁止外链、内容类型不符或只接受付费投稿：skipped，说明实际规则。
- 投稿要求超出当前任务的长期运营、社群互动或其他文章修改时，不自动扩展为新的发布工作。
