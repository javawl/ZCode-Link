# 目录站 / 导航站（category: 导航站）

改编自 link-harness 2.0.0 同名 playbook；共同的授权、查重、租约、浏览器页面引用和结果字段遵循 [主技能](../../SKILL.md)。

## 流程

1. 优先 `submitUrl`；没有时从 `sourceUrl` 页面里实际看到的 Submit / Add site / 提交链接入口进入。先查公开列表，避免重复收录。
2. 读取表单快照，常见字段为网站名、URL、一句话描述、长描述、分类、Logo、邮箱。每个 `backlinks_browser` 调用使用本项专属 `page`。
3. 优先使用网站资料包。描述按字段实际字符限制选择短、中、长版本，常见可参考 80 / 160 / 400 字符，但以页面计数和校验为准；内容围绕网站真实功能，不堆关键词。
4. 分类只选真实贴近项；定价和功能以资料包为准，不因想通过审核虚填。
5. 邮箱使用 `backlinks` 的 `mailbox_create`，`localPart` 取唯一前缀，域名由 `mailboxDomain` 配置或用户明确指定。调用 `mail_wait` 获取真实验证邮件；验证码/链接只用于刚发起的站点注册流程，保持租约保活。
6. 如果要求互链徽标，先完成下面的徽标核验，再最终提交。
7. 提交前 snapshot 复查网站 URL、分类、描述和素材；最终提交只做一次。记录真实回执，公开详情页已核验目标链接为 live，明确待审为 submitted，未知结果为 manual_required。

## 互链和域名验证

- 互挂徽标：读取目标站实际徽标 HTML → 核对己方是否已挂 → `badge_add` → 检查后端已配置回调结果 → 读取己方公开页确认链接真正生效 → 才回目标站 Verify / 提交。
- 不猜测己方刷新接口，不拼接固定 `/footer/refresh` 地址；`callbackTriggered` 也不代表公开页已生效。公开页面未更新时按 [主技能](../../SKILL.md) 的有界复核与人工处理流程执行。
- 要求 meta 标签、DNS 或文件验证：只有用户已授权且有真实可用的项目操作入口时才执行对应配置；否则记录需要的具体标签/路径，manual_required，不能假称已经加上。
- 收费是唯一提交渠道时 skipped（付费）；有免费渠道时可以继续免费流程，不购买加速服务。
