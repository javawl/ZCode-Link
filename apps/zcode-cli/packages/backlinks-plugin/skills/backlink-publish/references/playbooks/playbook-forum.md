# 论坛 / 群组讨论（category: 论坛）

改编自 link-harness 2.0.0 同名 playbook；遵循 [主技能](../../SKILL.md) 的租约、查重、页面隔离和一次最终提交规则。

## 流程

1. 先读版规、外链限制、账号资格和既有收录；推广网站已存在有效链接或有后台提交记录时不再发帖。
2. 可使用 cloud-mail 邮箱注册、收取验证码/验证链接后登录；Google 登录按 [会话指南](../google-session.md) 处理。普通登录需求不直接等于 manual_required。
3. 检查个人资料的 Website / signature 是否允许外链。按用户发布范围填写真实资料与目标链接；如果公开资料页已经提供所需链接，直接核验并结束本项，不额外发帖。
4. 确需发帖才能显示签名且版规允许时，挑相关版块写一篇有真实价值的提问或分享，结合推广网站实际用途，不编造使用经历、不刷广告。
5. 没有签名的群组/讨论式站点可按 [博客编辑器规则](playbook-blog.md) 在正文携带一个目标链接。富文本用工具栏，只有明确支持 HTML / BBCode 时才输入相应标记；不能因为站点叫 Wix 就默认 `<a>` 直写有效。
6. 最终提交后读取回执并检查公开帖子、签名或个人资料页。实际链接公开可达才 live；待审核写 submitted；结果未知或转义未生效写 manual_required，不重发。

## 边界

- 新账号发帖数、邀请、声望或等待期门槛：manual_required，写清真实门槛，不通过无意义刷帖绕过。
- 版规禁止广告/外链：skipped（规则），即使表单能输入也不发布。
- 需要个人身份、实名认证或绑定未授权社交账号：manual_required。
- 修改已存在帖子、声明所有权或管理其他人的内容不属于普通新条目发布；沿用用户明确授权的范围，不能自行扩展。
