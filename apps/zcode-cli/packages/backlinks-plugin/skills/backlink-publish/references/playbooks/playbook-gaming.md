# 游戏站（category: 游戏站）

改编自 link-harness 2.0.0 同名 playbook；适用于游戏目录、独立游戏平台等，基础流程见 [目录 playbook](playbook-directory.md)，共同规则见 [主技能](../../SKILL.md)。

## 流程

1. 从 submitUrl / sourceUrl 勘察实际入口和资格。确认推广项目确实属于站点接受的游戏类型，不把普通工具伪装成游戏。
2. 常见字段包括游戏名、简介、玩法、平台、类型标签、截图/封面、网站或试玩链接。事实优先用网站资料包和推广网站公开页面。
3. 优先使用资料包 screenshotUrl / logoUrl 等授权素材；缺失时从推广网站获取可用截图/封面。上传前下载为工作区内真实文件；不能将远程图片 URL 直接传给 upload。
4. 描述游戏的实际玩法和亮点，平台/分类标签如实填写。站点有图片尺寸要求时使用有权处理的素材并验证；没有素材且无法取得时 manual_required，明确缺什么。
5. 注册、邮箱验证、Google 登录和互链徽标按主流程执行。提交前复核字段、素材与链接，只执行一次最终提交。
6. 检查公开游戏详情页的实际可点击链接；核验通过 live，明确待审核 submitted，未知提交 manual_required。

## 边界

- 要求可运行 build、下载包、作者授权或平台资质而当前没有：用户可提供且已选择继续时 manual_required，否则 skipped（资格不符）。
- 不上传伪造或无权分发的游戏包，不从工作区外收集文件。
- 如只有付费上架渠道，skipped（付费）；存在免费渠道则可在原授权范围内继续。
