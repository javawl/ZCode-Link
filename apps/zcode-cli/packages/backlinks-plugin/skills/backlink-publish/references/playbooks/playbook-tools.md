# 工具站 / AI 工具目录（category: 工具站）

改编自 link-harness 2.0.0 同名 playbook；适用于工具发现平台和 AI 导航，基础流程见 [目录 playbook](playbook-directory.md)，共同规则见 [主技能](../../SKILL.md)。

## 流程

1. 从 submitUrl 或页面真实 Submit tool 入口进入，先站内搜索推广网站，核对已有列表和后台发布记录。
2. 常见字段包括工具名、URL、一句话 pitch、长描述、功能标签、Free / Freemium / Paid、Logo、截图和社交链接。优先使用网站资料包，缺失事实从推广网站公开信息核实。
3. pitch 一句话说明真实用户问题与工具用途；定价档、免费限制和功能如实填写，不把试用或付费工具描述成永久免费。
4. 图片先保存为当前工作区真实文件再 upload；社交链接只有用户已提供或推广网站公开确认时填写，不编造账号。
5. 邮箱验证走 mailbox_create / mail_wait；Google 登录走明确页引用的 OAuth 流程。需要绑定其他社交账号、身份认证或提供缺失资质时 manual_required。
6. 要求互链徽标时，先 badge_add 并核验己方公开页面实际链接，再执行目标站的 Verify / 最终提交；不猜刷新 URL。
7. 最终提交一次，公开工具详情页链接核验成功为 live，明确进入审核队列为 submitted，未知回执为 manual_required。

## 已有列表与 Claim your listing

已有有效列表时不重复新建，汇总其公开链接。若用户明确要求认领已有列表，可按站点真实 claim 流程验证所有权；普通批次发布不自动扩展成替换列表内容或声明未确认的所有权。所需验证材料缺失时记人工处理。

来源标签按真实观察添加：免费可提交且无需徽标可标“免徽章”，要求徽标标“要徽章”，成功提交或核验上线标“可复用”，只有付费途径标“付费”。“可复用”不代表本推广网站可重复发布。
